## Loyiha maqsadi

Ko'pchilik ishlarini daftarga yozadi: kechqurun ertangi ishlar ro'yxati tuziladi, kun davomida ular belgilanadi. Lekin daftar maqsadga qanchalik yaqinlashganingizni, qaysi kunlari bo'shashganingizni yoki qaysi ish doim ertaga qolib ketayotganini ko'rsatmaydi.

**Isloh** shu daftarning aqlli varianti. U uchta savolga javob beradi:

1. **Qayerga ketyapman?** Muddati bor maqsadlar va har bir maqsad uchun kunlik me'yor.
2. **Bugun nima qilaman?** Kun 5 ta namoz bo'yicha bloklarga bo'lingan, har bir ish o'z blokida turadi.
3. **Qanday ketyapman?** Har kun yashil, sariq yoki qizil rangga bo'yaladi. Dastur kamchiliklaringizni topib, aniq maslahat beradi.

Bosh sahifada esa doim katta soat turadi: yil tugashiga va asosiy maqsadingiz muddatiga qolgan vaqt soniyalab kamayib boradi. Bu vaqt qanchalik tez o'tayotganini doimo eslatib turadi.

> Dastur ro'yxatdan o'tishni so'ramaydi, internetga ulanmaydi va hech qanday ma'lumot yubormaydi. Hamma narsa faqat sizning qurilmangizda saqlanadi.

## Imkoniyatlar

| Bo'lim | Nima qiladi |
|---|---|
| 🏠 **Bosh sahifa** | Sana, millisekundli katta soat, yil tugashiga va asosiy maqsadga qolgan vaqt. Fonga o'z rasmingizni qo'yasiz, panellar iOS uslubidagi xira shisha ko'rinishida. |
| ☀️ **Bugun** | Bomdod, Peshin, Asr, Shom va Xufton bloklari. Har bir blokda shu namozdan keyingi ishlar turadi. Namozni “vaqtida”, “kech” yoki “qazo” deb belgilaysiz. Keyingi namozgacha qolgan vaqt va kunlik ball ko'rinib turadi. Kechqurun “Kunni yakunlash” tugmasi bor. |
| 📅 **Ertaga** | Bugundan qolgan ishlar va maqsadlardan avtomatik takliflar chiqadi. Ishni sudrab blokka joylaysiz, eng muhim 3 tasini ★ bilan belgilab, rejani yopasiz. |
| 🎯 **Maqsadlar** | 3 xil maqsad bor. **Raqamli**: masalan 300 bet. **Muntazam**: har kuni 1 soat. **Bosqichli**: loyiha bosqichlari. Kunlik me'yor, rejadan oldinda yoki orqadaligingiz va “shu sur'atda qachon yetasiz” prognozi ko'rinadi. Bir vaqtda ko'pi bilan 3 ta faol maqsad bo'ladi. |
| 👤 **Profil** | Yosh va keyingi tug'ilgan kunga qolgan vaqt jonli hisoblanadi. GitHub'dagidek 12 oylik faollik jadvali va alohida namozlar jadvali bor. Ketma-ket yashil kunlar soni ko'rsatiladi, avtomatik tahlil va maslahatlar beriladi. Bosh sahifa fon rasmi shu yerdan sozlanadi. |
| ⚙️ **Sozlamalar** | Shahar, mazhab (Hanafiy yoki Shofi'iy) va har bir namozga ± daqiqa tuzatish. Eslatmalar, hijriy sana va zaxira nusxa shu yerda. |

**Eslatmalar** namozdan oldin, namoz vaqti kirganda va Bomdod tugashidan oldin keladi. Aniq vaqtli ishlar va reja tuzilmagan kechalar haqida ham eslatadi. Kompyuterda oyna yopiq bo'lsa ham, telefonda esa dastur ochiq bo'lmasa ham ishlaydi.

## O'rnatish

Yuqoridagi tugmalardan o'z tizimingiz uchun faylni yuklab oling. Dastur bepul va reklamasiz.

> Dastur hozircha Apple, Microsoft yoki Google do'konlarida emas. Shuning uchun o'rnatishda tizim bir marta ogohlantirish chiqarishi mumkin. Bu normal holat, quyida qanday o'tish kerakligi yozilgan.

### Windows 10/11

1. **Isloh-Windows-Setup.exe** ni yuklab oling va ikki marta bosing.
2. Agar “Windows protected your PC” oynasi chiqsa: **More info** → **Run anyway** ni bosing.
3. Dastur o'zi o'rnatiladi va ochiladi. Ish stolida hamda Start menyusida “Isloh” ikonkasi paydo bo'ladi.

### macOS

1. Mac'ingiz turini aniqlang: ** → Bu Mac haqida** oynasida “Chip: Apple M…” yozilgan bo'lsa **arm64** faylni, “Intel” yozilgan bo'lsa **x64** faylni yuklab oling.
2. `.dmg` faylni oching va **Isloh** ikonkasini **Applications** papkasiga sudrang.
3. Birinchi ochishda “Apple could not verify…” xabari chiqadi:
   - **Tizim sozlamalari → Maxfiylik va xavfsizlik** bo'limini oching. Pastda “Isloh was blocked…” yonidagi **Baribir ochish (Open Anyway)** tugmasini bosing.
   - Yoki Terminalda bitta buyruq yetarli:
     ```bash
     xattr -dr com.apple.quarantine /Applications/Isloh.app
     ```
4. Shundan keyin dastur oddiy ochilaveradi.

### Linux

**Ubuntu, Debian, Linux Mint, Pop!_OS:**
```bash
sudo apt install ./Isloh-Linux.deb
```
Yoki faylni ikki marta bosib “App Center” orqali o'rnating. Dastur ilovalar menyusida **Isloh** nomi bilan chiqadi.

**Boshqa distributivlar (AppImage):**
```bash
chmod +x Isloh-Linux.AppImage
./Isloh-Linux.AppImage
```
Ubuntu 22.04 va undan yangi versiyalarda AppImage uchun `sudo apt install libfuse2` kerak bo'lishi mumkin. Shu sababli Ubuntu'da `.deb` faylni tavsiya qilamiz.

### Android 7 va undan yangi

1. Telefoningizda **Isloh-Android.apk** ni yuklab oling va oching.
2. “Noma'lum manbadan o'rnatish” so'ralsa: **Sozlamalar** → brauzeringiz (masalan Chrome) → **Bu manbadan ruxsat berish**.
3. **O'rnatish** ni bosing. Play Protect ogohlantirsa, **Baribir o'rnatish** ni tanlang.
4. Dasturni birinchi ochganda **bildirishnomalarga ruxsat bering**, aks holda namoz eslatmalari kelmaydi.
5. Ba'zi telefonlar (Xiaomi, Samsung, Huawei) batareyani tejash uchun eslatmalarni to'xtatib qo'yadi. Ishonchli ishlashi uchun: **Sozlamalar → Ilovalar → Isloh → Batareya → Cheklovsiz**.

## Qanday foydalaniladi

### Birinchi ochilishda
Dastur 5 qadamda sizga moslashadi:
1. Ism.
2. Tug'ilgan sana. Undan yosh va keyingi tug'ilgan kun hisoblanadi.
3. Shahar. Shu shahar uchun namoz vaqtlari ko'rsatiladi.
4. Kun tartibi va asosiy yo'nalishlar: Din, Bilim, Sog'liq, Kasb, Oila, Moliya.
5. Birinchi maqsad. Bu qadamni o'tkazib yuborish mumkin.

### Har kungi tartib

```
 Kechqurun (Xuftondan keyin)          Kun davomida                   Natija
┌───────────────────────────┐   ┌──────────────────────────┐   ┌──────────────────────┐
│ Bugun → “Kunni yakunlash” │ → │ Bugun: ishlarni ✓,       │ → │ Profil: kun rangi,   │
│ Ertaga → ishlarni joylash │   │ namozlarni belgilash     │   │ tahlil va maslahatlar│
│ ★ eng muhim 3 ta → yopish │   │ eslatmalar o'z vaqtida   │   │                      │
└───────────────────────────┘   └──────────────────────────┘   └──────────────────────┘
```

1. **Maqsad qo'ying.** Masalan, “IELTS 7.0, 180 kun, har kuni 1 soat” yoki “300 bet kitob, 60 kun”. Dastur kunlik me'yorni o'zi hisoblaydi.
2. **Har kecha rejani tuzing.** Bugun panelida “Kunni yakunlash”ni bosing: bajarilmagan ishlarni ertaga o'tkazasiz yoki bekor qilasiz va bir-ikki qator xulosa yozasiz. So'ng Ertaga panelida maqsadlardan kelgan takliflarni va o'z ishlaringizni namoz bloklariga joylab, **Rejani yopish**ni bosing.
3. **Kun davomida belgilang.** Bajarilgan ishga ✓ qo'ying. Raqamli maqsadga bog'langan ish bo'lsa, dastur “Nechta bet o'qidingiz?” deb so'raydi va maqsad progressi o'zi yangilanadi.
4. **Profilni haftada bir ko'ring.** Qaysi blokda ko'p ish qolayotganini, qaysi ish doim ko'chirilayotganini va qaysi maqsad orqada qolayotganini dastur o'zi aytadi.

**Klaviatura (kompyuterda):**
- **Ctrl+1…6:** bo'limlar
- **Ctrl+N:** tez ish qo'shish
- **Enter:** qo'shish
- **Esc:** oynani yopish

### Kun rangi qanday hisoblanadi

**Ball** = bajarilgan ishlar og'irligi ÷ rejadagi ishlar og'irligi.

Har bir ishning og'irligi: ★ eng muhim ish — **3**, maqsadga bog'langan ish — **2**, oddiy ish — **1**.

| Rang | Shart |
|---|---|
| 🟩 To'q yashil | 100% bajarildi |
| 🟩 Yashil | 80–99% |
| 🟨 Sariq | 40–79% |
| 🟥 Qizil | 0–39% yoki reja umuman tuzilmagan |
| ⬜ Kulrang | Uzrli kun (kasallik, safar), oyiga ko'pi bilan 3 ta |

**Halollik qoidalari:**
- Kun keyingi **Bomdodda qulflanadi**. O'tgan kunni o'zgartirib bo'lmaydi.
- Ertaga ko'chirilgan yoki bekor qilingan ish bajarilmagan hisoblanadi.
- Rejada 3 tadan kam ish bo'lsa va birorta maqsad ishi bo'lmasa, kun sariqdan yuqori chiqmaydi. Bitta oson ish yozib, yashil olib bo'lmaydi.

Kun **Bomdoddan** boshlanadi. Yarim tundan keyin ham, Bomdod kirgunicha, “Bugun” kechagi kun hisoblanadi.

## Namoz vaqtlari

- Vaqtlar astronomik formula bilan **internetsiz** hisoblanadi, istalgan yil uchun ishlaydi.
- Hisob [namozvaqti.uz](https://namozvaqti.uz) dagi **Toshkent 2026 yillik jadvali** bilan solishtirib sozlangan. Yil davomida o'rtacha farq 0,3 daqiqadan kam, ba'zi kunlari 1 daqiqa, Xuftonda ayrim kunlarda 3 daqiqagacha.
- Viloyat markazlarini tanlash mumkin. Ular uchun ham hisoblash shu usulda, lekin rasmiy jadvaldan farq bir necha daqiqagacha bo'lishi mumkin. Sozlamalarda har bir namozga ± daqiqa qo'shib, masjidingiz jadvaliga moslang.
- Boshqa joylar uchun “Boshqa joy (koordinata)” bandini tanlab, kenglik, uzunlik va vaqt mintaqasini kiritasiz.
- Mazhab bo'yicha Asr vaqtini tanlash mumkin: Hanafiy yoki Shofi'iy.

## Ma'lumotlar va zaxira

| Qurilma | Ma'lumot qayerda |
|---|---|
| Windows | `%APPDATA%\Isloh\isloh-data.json` |
| macOS | `~/Library/Application Support/Isloh/isloh-data.json` |
| Linux | `~/.config/Isloh/isloh-data.json` |
| Android | Ilovaning ichki xotirasi |

- Kompyuterda **har kuni avtomatik zaxira** olinadi (`backups/` papkasi, oxirgi 30 kun saqlanadi).
- **Sozlamalar → Zaxira faylini saqlash** bitta `.json` fayl yaratadi. Bu faylni istalgan qurilmada **Zaxiradan tiklash** orqali ochish mumkin. Masalan, kompyuterdan telefonga o'tish shunday qilinadi.
- Telefonda dasturni o'chirsangiz, ma'lumotlar ham o'chadi. Vaqti-vaqti bilan zaxira faylini saqlab qo'ying.

## Dasturchilar uchun

Dastur bitta umumiy kod asosida ishlaydi. Interfeys va mantiq `www/` papkasida, oddiy HTML, CSS va JavaScript'da yozilgan, freymvork ishlatilmagan. Bu kod quyidagi qobiqlar ichida ishga tushadi:
- **Electron:** Windows, macOS va Linux uchun.
- **Capacitor:** Android uchun.

```
www/
  index.html, style.css, app.js   interfeys
  core/prayer.js                  namoz vaqtlarini hisoblash (kalibrlangan)
  core/backend.js                 maqsadlar, ishlar, profil tahlili, eslatmalar
  core/store.js                   saqlash: fayl (kompyuter) yoki IndexedDB (telefon)
electron/                         kompyuter qobig'i: oyna, tray, avtomatik ishga tushish
android/                          Android loyihasi (Capacitor)
build/                            ikonka va yig'ish sozlamalari
.github/workflows/release.yml     4 ta tizim uchun avtomatik yig'ish
```

### Ishga tushirish
```bash
npm install
npm start              # kompyuter versiyasi (Electron)
npm run web            # brauzerda: http://localhost:8080
```

### Yig'ish
```bash
npm run dist:linux     # dist/Isloh-Linux.deb, dist/Isloh-Linux.AppImage
npm run dist:win       # dist/Isloh-Windows-Setup.exe (Windows'da)
npm run dist:mac       # dist/Isloh-macOS-*.dmg (macOS'da)
npx cap sync android && cd android && ./gradlew assembleRelease   # Android (Java 21 + Android SDK)
```

### Yangi versiya chiqarish
`package.json` dagi versiyani oshiring va teg yuboring:
```bash
git tag v1.0.1
git push origin v1.0.1
```
GitHub Actions 4 ta tizim uchun fayllarni o'zi yig'adi va [Releases](https://github.com/olimovswe/isloh/releases) sahifasiga joylaydi. README'dagi tugmalar doim eng oxirgi versiyani yuklaydi.

### Android imzo kaliti
Yangi versiya eski versiya ustidan o'rnatilishi uchun APK har safar bir xil kalit bilan imzolanishi kerak. Kalitni GitHub'ga bir marta qo'shib qo'yasiz: **Settings → Secrets and variables → Actions** bo'limida quyidagi 4 ta sir yaratiladi:
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Sirlar berilmasa, APK vaqtinchalik kalit bilan imzolanadi. U ham o'rnatiladi, lekin yangilashda eski versiyani o'chirib, qayta o'rnatish kerak bo'ladi.
